## 使用场景

本Skill用于指导agent完成以下网页搜索与打开操作：

- 使用百度搜索引擎指定关键词
- 提取搜索结果中的有效网页链接
- 过滤广告、重定向、重复内容等无效链接
- 优先选择官方网站和高品质页面
- 在新标签页中打开前N条相关网页链接

## 触发场景

当用户表达以下意图时，Agent 会自动应用此 Skill：

| 场景类型 | 示例语句 |
|---------|---------|
| **查找单个页面** | "帮我找到银河麒麟操作系统页面" |
| **指定数量查找** | "帮我找2个银河麒麟镜像相关的网页" |
| **搜索并打开结果** | "搜索 XXX 并打开前几个结果" |
| **打开多个相关网页** | "帮我打开几个关于 XXX 的网页" |

**触发关键词**：`搜索`、`找网页`、`打开网页`
## 支持的平台

- **百度** (www.baidu.com) - 主要支持的搜索引擎
- **bing** (www.cn.bing.com) - 支持的搜索引擎

## 提示词模板

### 基础模板
搜索"{搜索关键词}"并打开前{打开数量}个相关网页。

任务步骤：

1. 打开百度搜索页面
2. 等待页面加载完成
2. 输入搜索关键词：{搜索关键词}
3. 点击回车键等待搜索结果加载完成
4. 提取前{打开数量}条搜索结果链接
5. 过滤无效链接（广告、重定向、重复内容等）
6. 在新标签页中依次打开有效链接

### 百度搜索示例

**用户需求：**
> 帮我找2个银河麒麟镜像相关的网页。

**完整提示词：**
> 在百度上搜索银河麒麟镜像并打开前2个相关网页。


## 工作流程

- 打开百度搜索页面（ https://www.baidu.com/ ）
- 等待页面加载完成
- 输入搜索关键词：银河麒麟镜像
- 点击回车键等待搜索结果加载完成
- 提取前2条搜索结果链接
- 跳过广告、推广、重定向、空连接或无效链接
- 在新标签页中打开有效链接

**注意事项**
- 仅支持百度搜索引擎。
- 如果用户未指定打开数量，默认打开2-3个网页，最多不超过10个。
- 如果搜索结果为空，告知用户没有搜索到相关内容。
- 优先选择官方网站和高品质页面。
- 避免重复域名，同一域名尽量只保留一个结果。
- 必须记录任务完成时间。

## 变量说明

| 变量 | 说明 | 示例 |
|------|------|------|
| `{搜索关键词}` | 用户要搜索的内容 | 银河麒麟操作系统、银河麒麟镜像 |
| `{打开数量}` | 需要打开的网页数量 | 2、3、5 |

## agent-browser 实操指南

1. 关闭之前的浏览器用例并添加agent-browser执行路径
```bash
# 步骤1：关闭agent-browser用例
agent-browser close --all

# 步骤2：PATH环境变量添加agent-browser执行路径
NODE_BIN="$HOME/.nvm/versions/node/$(ls $HOME/.nvm/versions/node | sort -Vr | head -n1)/bin"
if [[ -d "$NODE_BIN" && ! ":$PATH:" =~ ":$NODE_BIN:" ]]; then
    export PATH="$NODE_BIN:$PATH"
fi
```

2. 启动浏览器并开启远程调试

```bash
# 启动 kylin-browser 并开启远程调试端口
nohup kylin-browser --remote-debugging-port=9223 "{搜索引擎}" >/dev/null 2>&1 &
```

3. 连接浏览器:

```bash
# 等待页面加载完毕并连接到已启动的浏览器
sleep 3 && agent-browser connect 9223
```
4. 执行自动化操作：

### 输入搜索关键词

```bash
# 步骤1: 查找搜索引擎输入框
agent-browser snapshot -i | grep textbox
# 步骤2: 输入搜索关键词
agent-browser fill @<ref1> "{搜索关键词}"
# 步骤3: 点击回车键
agent-browser press Enter
```

### 提取搜索结果链接（百度搜索引擎）

```bash
# 步骤1: 查找搜索结果链接
agent-browser eval '((n) => {
   const results = [...document.querySelectorAll("h3 a")]
      .slice(0, n)
      .map((a, i) => ({
      index: i + 1,
      text: a.innerText,
      href: a.href
      }));
   return results;
})({打开数量})
```

### 提取搜索结果链接（bing搜索引擎）

```bash
# 步骤1: 查找搜索结果链接
agent-browser eval "((n) => {
  const items = document.querySelectorAll('li.b_algo > h2 a, li.b_ans > h2 a');
  return [...items].slice(0, n).map((a, i) => ({
    index: i + 1,
    text: a.innerText.trim(),
    href: a.href
  }));
})({打开数量});"
```

### 在新标签页中打开提取到的网页

```bash
# 步骤1: 打开新标签页加载提取到的网页
agent-browser tab new "<href>"
```

## 异常处理

- `搜索结果为空`：告知用户没有搜索到相关内容，建议更换关键词。
- `提取链接为空`：检查页面是否加载完成，或百度页面结构是否发生变化。
- `无效链接`：跳过广告链接、推广链接、登录/重定向页面、空连接。
- `重复域名`：同一域名尽量只保留一个结果。
- `新标签页打开失败`：检查链接是否为有效的 HTTP/HTTPS 网址。
- `网络加载失败`：让用户检查网络连接，确保浏览器可以访问互联网。
- `页面元素未找到`：检查元素是否在页面上可见，是否被其他元素遮挡，必要时等待页面加载完成。
- `agent-browser找不到`：使用命令`which agent-browser`检查agent-browser是否在系统路径中。
