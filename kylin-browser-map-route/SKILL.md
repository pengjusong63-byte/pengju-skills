# 地图路线查询 Skill

## 使用场景

本 Skill 用于指导 agent 完成以下地图操作：

- 打开指定的地图网站（支持百度地图）
- 输入起点和终点
- 搜索地图路线

## 触发场景

当用户表达以下意图时，Agent 会自动应用此 Skill：

| 场景类型       | 示例语句             |
| ---------- | ---------------- |
| **直接路线查询** | "查一下北京到上海的路线"  |
| **简化表达**   | "从广州开车去深圳怎么走"    |
| **平台指定**   | "用百度地图搜杭州到南京的路线" |
| **交通方式指定** | "搜一下成都到重庆的驾车路线"  |

**触发关键词**：`地图`、`路线`、`开车去`、`规划路线`

## 支持的平台

- **百度地图** (map.baidu.com) - 主要支持

## 提示词模板

1. 从用户输入中识别并抽取：起点、终点、平台（默认百度地图）、出行方式（默认驾车）。

## 注意事项

- 如果搜索结果为空或提示"请选择正确的起点、途经点或终点"，请尝试更换关键词（如添加省/市全称）重新搜索
- 如果用户指定出行方式不是默认驾车，则需选择对应的按钮（如"公交"、"步行"等）
- 在执行`自动化`->`结果页面展示`时，要保证在搜索结果标签页弹出给用户展示，用户可以查看并确认搜索结果（必须执行）
- 禁止生成总结、摘要或格式化报告

### 基础模板

## 变量说明

| 变量       | 说明             | 示例                      |
| -------- | -------------- | ----------------------- |
| `{平台}`   | 地图网站名称（默认百度地图） | 百度地图                    |
| `{平台网址}` | 地图网站URL        | <https://map.baidu.com> |
| `{起点}`   | 出发地名称          | 北京                      |

## agent-browser 实操指南（以百度地图为例）

### 1. 关闭之前的浏览器会话并添加agent-browser执行路径

```bash
# 步骤1：关闭所有agent-browser会话实例
agent-browser close --all 

# 步骤2：PATH环境变量添加agent-browser执行路径
NODE_BIN="$HOME/.nvm/versions/node/$(ls $HOME/.nvm/versions/node | sort -Vr | head -n1)/bin"
if [[ -d "$NODE_BIN" && ! ":$PATH:" =~ ":$NODE_BIN:" ]]; then
    export PATH="$NODE_BIN:$PATH"
fi
```

### 2. 启动麒麟浏览器并开启远程调试

```bash
# 步骤1: 启动 kylin-browser 并开启远程调试端口
nohup kylin-browser --remote-debugging-port=9225 "https://map.baidu.com" >/dev/null 2>&1 &

# 步骤2: 等待浏览器启动完成
while ! curl -s http://localhost:9225/json/version >/dev/null; do sleep 1; done

# 步骤3: 连接已启动的浏览器
agent-browser connect 9225

```

### 3. 执行自动化操作

\*\* 请用snapshot获取当前ref值，不要根据以下示例硬编码。 \*\*

#### 点击路线按钮

```bash
# 步骤1: 查看页面元素，找到路线按钮（通常是搜索框旁边的可点击图标）
# 在 snapshot 中，搜索框 textbox "搜地点、查公交、找路线" 旁边的 generic 
# ... clickable [cursor:pointer] 就是路线按钮图标，点击它。
agent-browser snapshot -i | grep -A1 "路线"

# 步骤2: 点击路线按钮
agent-browser click @<ref>

```

#### 填写起点、终点、出行方式关键词

```bash
# 步骤1: 查找起点输入|终点输入
agent-browser snapshot -i | grep -E "输入起点|输入终点|驾车|公交|步行|骑行"

# 步骤2: 填写起点|终点关键词
agent-browser fill @<ref1> "北京市" && agent-browser fill @<ref2> "上海市"

# 步骤3: 点击目标出行方式按钮
agent-browser click @<ref3>
```

#### 发起路线查询

```bash
# 步骤1: 查找搜索按钮
agent-browser snapshot -i | grep -E "button"

# 步骤2: 点击搜索按钮
agent-browser click @<ref>

```

#### 结果页面展示（必须执行：切换至搜索结果标签页）

> 本步骤为强制步骤，无论当前是否已显示结果，都必须执行，用于将搜索结果标签页展示给用户。

```bash
# 步骤1: 列出所有标签页，切换到最后一个标签页（即搜索结果标签页），不得跳过
TAB_INDEX=$(agent-browser tab list | tail -n 1 | awk -F'[][]' '{print $2}') && agent-browser tab $TAB_INDEX

# 步骤2: 验证切换成功，获取当前标签页标题
agent-browser tab docs

```

### 4. 异常处理

- **执行agent-browser时出错，提示"agent-browser not found"**: 检查agent-browser是否已安装并启动。
- **agent-browser连接端口失败**：检查端口是否被占用，或是否已关闭。
- **页面加载超时**：等待超过 10 秒仍未出现目标元素，则截图并提示用户检查网络。
- **搜索无结果**：若提示"未找到路线"，尝试给起点/终点添加省/市全称后重新搜索。
- **元素找不到**：刷新页面重试；若仍失败，停止任务并报错。
- **遇到登录弹窗**：提示用户手动处理登录。
- **结果解析失败**：输出原始页面内容，由用户确认。

### 5. 输出原始结果 
直接输出从百度地图页面提取的路线原始信息，禁止生成总结、摘要或格式化报告。输出任务用时 X 秒（例如 35 秒）

## 常见问题
- **搜索结果为空**：参考「异常处理 > 搜索无结果」流程处理。
- **提示请选择正确的起点/途经点/终点**：尝试给起点/终点添加省/市全称后重新搜索。
