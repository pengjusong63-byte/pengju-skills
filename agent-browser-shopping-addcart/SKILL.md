# 电商购物车自动化 Skill

## 使用场景

本 Skill 用于指导 agent 完成以下电商操作：
- 在电商平台搜索指定商品
- 根据条件筛选商品（品牌、价格、规格等）
- 选择合适的商品 SKU
- 将商品加入购物车
- 点击购物车 （兼容淘宝）

## 触发场景

当用户表达以下意图时，Agent 会自动应用此 Skill：

| 场景类型 | 示例语句 |
|---------|---------|
| **直接购物需求** | "想在京东上买惠普 U盘 64G 100块左右加入到购物车" |
| **简化表达** | "帮我买iphone 16手机加入购物车" |
| **平台指定** | "京东买 Nike 鞋子 42码" |
| **工具指定** | "用 agent-browser 在京东买 XX" |

**触发关键词**：`买`、`购物`、`加入购物车`、`京东`、`自动化购物`

## 支持的平台

- **京东** (jd.com) - 主要支持

## 提示词模板

### 基础模板

```
我想在{平台}上买{商品描述}，价格{价格范围}，帮我加入购物车。

任务步骤：
1. 打开 {平台网址}
2. 在搜索框中搜索 "{商品关键词}"
3. 等待页面加载完成，获取搜索结果列表
4. 根据以下条件筛选商品：
   - 品牌：{品牌}
   - 规格：{规格}
   - 价格范围：{价格范围}
5. 点击符合条件的第一个商品进入详情页
6. 在详情页选择所需规格（如容量、颜色等）
7. 确认价格符合预期
8. 点击"加入购物车"按钮
9. 点击"购物车"按钮
10. 确认添加成功提示

注意事项：
- 如果搜索结果为空，请尝试更换关键词重新搜索
- 如果指定规格缺货，请选择相近的可用规格
- 如果价格超出范围，请停止操作并告知用户
- 操作完成后报告商品名称、最终价格、所选规格
```

### 京东示例

**用户需求：**
> 想在京东上买惠普 U盘 64G 100块左右加入到购物车。

**完整提示词：**

```
想在京东上买惠普 U盘 64G，100块左右，帮我加入购物车。

任务步骤：
1. 打开 https://www.jd.com
2. 在搜索框中搜索 "惠普 U盘 64G"
3. 等待页面加载完成，获取搜索结果列表
4. 根据以下条件筛选商品：
   - 品牌：惠普 (HP)
   - 容量：64GB
   - 价格范围：80-120元
5. 点击符合条件的第一个商品进入详情页
6. 在详情页选择所需规格（确认是64G容量）
7. 确认价格符合预期（100元左右）
8. 点击"加入购物车"按钮
9. 点击"购物车"按钮
10. 确认添加成功提示

注意事项：
- 如果搜索结果为空，请尝试更换关键词（如"HP U盘 64GB"）重新搜索
- 如果64G规格缺货，请选择相近的可用规格（如32G或128G），并告知用户
- 如果价格超出80-120元范围，请停止操作并告知用户
- 操作完成后报告：商品名称、最终价格、所选规格、容量
```

## 变量说明

| 变量 | 说明 | 示例 |
|------|------|------|
| `{平台}` | 电商平台名称 | 京东 |
| `{平台网址}` | 电商网站URL | https://www.jd.com |
| `{商品描述}` | 用户想要的商品 | 惠普 U盘 64G |
| `{商品关键词}` | 用于搜索的关键词 | 惠普 U盘 64G |
| `{品牌}` | 品牌名称 | 惠普、HP |
| `{规格}` | 商品规格参数 | 64G、64GB |
| `{价格范围}` | 可接受的价格区间 | 80-120元、100块左右 |

## 进阶使用

### 多商品批量添加

如需添加多个商品到购物车，请分别执行多次任务，每次添加一个商品。

### 处理登录状态

如需添加商品到购物车时需要登录：
1. 检测到登录页面时暂停操作
2. 提示用户需要登录
3. 等待用户完成登录后恢复操作

## agent-browser 实操指南

### 1. 关闭之前的浏览器用例

```bash
# 关闭agent-browser用例
agent-browser close --all
```

### 2. 启动浏览器并开启远程调试

```bash
# 启动 kylin-browser 并开启远程调试端口
nohup kylin-browser --remote-debugging-port=9224 "https://www.jd.com" >/dev/null 2>&1 &
```

### 3. 连接浏览器

```bash
# 等待页面加载完毕并连接到已启动的浏览器
sleep 5 && agent-browser connect 9224
```

### 4. 执行自动化操作

#### 搜索商品

使用 `snapshot -i` 交互式查找元素，通过语义定位搜索框：

```bash
# 步骤1: 查看页面元素，找到搜索框
agent-browser snapshot -i | grep "搜索"
# 输出示例：
# - textbox "搜索" [ref=e308]: 请输入搜索内容
# - generic "搜索" [ref=e309] clickable [cursor:pointer]
# - button "搜索" [ref=e374]

# 步骤2: 在搜索框中填入关键词
agent-browser fill @e308 "惠普 U盘 64G"

# 步骤3: 点击搜索按钮
agent-browser click @e374

```

**查找元素技巧：**

| 场景 | 命令 | 说明 |
|------|------|------|
| 找搜索框 | `snapshot -i \| grep "搜索"` | 过滤包含"搜索"的元素 |
| 找输入框 | `snapshot -i \| grep "textbox"` | 过滤文本输入框 |
| 找按钮 | `snapshot -i \| grep "button"` | 过滤按钮元素 |
| 找可点击元素 | `snapshot -i \| grep "clickable"` | 过滤可点击元素 |

#### 获取搜索结果

```bash
# 步骤1: 查看搜索结果页面的所有商品元素

#    - generic "惠普存储京东自营旗舰店" [ref=e208] clickable [cursor:pointer, onclick]
```

#### 滚动查找更多商品

当搜索结果中找不到符合价格要求的商品时，可以通过滚动页面加载更多商品：

```bash
# 向下滚动 500 像素查看更多商品
agent-browser scroll down 500

# 再次查看搜索结果
agent-browser snapshot -i | grep -E "(价格|¥)" | head -10
```

**适用场景：**
| 场景 | 操作建议 |
|------|---------|
| 当前页无符合价格商品 | 执行 `scroll down 500` 加载更多商品 |
| 价格偏高/偏低 | 继续滚动查看更多价格选项 |
| 加载不完全 | 滚动后等待 2-3 秒再重新获取快照 |

**注意事项：**
- 每次滚动建议 500 像素，避免滚动过快导致页面加载不完全
- 滚动后需重新执行 `snapshot -i` 获取新加载的商品元素
- 通常滚动 1-3 次即可找到符合价格要求的商品

## 常见问题

**Q: 页面加载慢怎么办？**
A: 在每个操作后增加 `sleep` 等待时间，或使用 `setTimeout` 延迟执行下一步操作。

**Q: 找不到指定规格的商品怎么办？**
A: 优先选择最接近的可用规格，并在结果中告知用户所做的替换。

**Q: 价格与预期不符怎么办？**
A: 设置价格容忍范围（如±20%），超出范围时停止操作并询问用户。
